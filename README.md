# DEAD DISTRICT

市街地でゾンビの襲撃を生き残る、PCブラウザ向け3D TPSの試作です。Three.js + Vite を使用し、モデル・街並み・効果音はコードで生成しています。

制作時の依頼文と仕様確認への回答は、[制作プロンプト](prompt.log)に保存しています。

## 起動

Node.js 22.12以降を推奨します。

```sh
npm install
npm run dev
```

表示されたローカルURLをPCブラウザで開き「作戦開始」をクリックします。マウス固定に対応したChrome / Edgeなどのブラウザを推奨します。マウス固定が利用できない環境では、右ドラッグで視点操作できます。

```sh
npm test       # 当たり判定・爆風・経路探索の回帰テスト
npm run build # dist/ に本番用ファイルを生成
npm run preview
```

## 試作の仕様

- 1人プレイ、全5ウェーブ。敵数は8 / 12 / 16 / 20 / 24体。全滅させると6秒後に次ウェーブへ進みます。
- プレイヤーはHP100。ゾンビの近接攻撃は11ダメージ。HP0で敗北、5ウェーブ生存で勝利。
- ライフルは30発装填、予備弾無制限。通常34ダメージ、ヘッドショット95ダメージ、リロード1.7秒。
- ロケットは1発装填＋予備6発で開始。リロード2.2秒、爆風半径8m。近距離では自分も最大55ダメージを受けます。
- ウェーブ間にHP25回復、ロケット予備弾5発補給（上限12）、ライフルを再装填。
- エリア内の建物16棟・車両9台に耐久力があり、爆風で破壊できます。直撃は原則1発で破壊。爆風が端に当たる場合は複数回必要です。
- 破壊時には破片・煙・瓦礫が発生し、障害物の当たり判定が消えて通れるようになります。瓦礫は装飾です。
- 背景の街並み、道路、街灯、境界は破壊対象外。建物の内部・階層ごとの破壊・物理的な倒壊は未実装。
- ゾンビは経路探索で建物を迂回。破壊に合わせて経路を再計算します。
- ロケットの移動区間を判定して高速移動によるすり抜けを防ぎます。射撃は銃口側でも遮蔽物を確認します。
- 爆風は半径内の対象へ距離に応じてダメージを与えます。壁による爆風の遮蔽はありません。
- タブ切り替え・フォーカス喪失時も一時停止します。セーブ・マルチプレイ・ゲームパッド・スマートフォン操作には未対応。
- Google Fontsが利用できない場合はシステムフォントへフォールバックします。外部モデルや音声のダウンロードは不要です。

## 構成

- `src/main.js`: ゲーム進行、入力、カメラ、戦闘、HUD、音・エフェクト
- `src/world.js`: 市街地、車両、キャラクターの生成
- `src/simulation.js`: 当たり判定、爆風距離、経路探索
- `src/style.css`: タイトル画面とHUD
- `tests/simulation.test.js`: 描画に依存しない回帰テスト

開発サーバーに `?test` を付けると `window.__game` に検証用のゲーム状態・操作関数を公開します。`?test&selftest` を付けると実際の3Dシーン・戦闘処理を使う10件の結合テストを実行し、結果を画面に表示します。本番ビルドでは検証機能を公開しません。
